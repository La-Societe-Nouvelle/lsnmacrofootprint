# Source

Ces tables de reference (bridges CRF <-> NACE, coefficients menages,
nomenclatures pays/industries) sont reprises telles quelles du projet
[InseeFrLab/global-ghg-emissions](https://github.com/InseeFrLab/global-ghg-emissions)
(Sylvain Larrieu, Insee), qui a implemente et valide la replication de la
methodologie Eurostat decrite dans *FIGARO - Greenhouse gas emission
estimates - Methodological note* (Eurostat, 18 novembre 2024).

Utilisees par `obs_accounts/ghg/ghg_accounts_extensions.R` - voir l'en-tete de
ce fichier pour le detail des credits.
